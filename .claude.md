## 2. Typography System

### Font Stack
```css
font-family: system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
```
**Note**: Relies on native system fonts for optimal performance and Japanese character support.

### Font Size Hierarchy

| Element | Mobile | Desktop | Line Height | Tailwind Classes |
|---------|--------|---------|-------------|------------------|
| **Large Heading** | 18px | 24px | 2.0-2.2 | `text-[18px] lg:text-[24px] leading-[2] lg:leading-[2.2]` |
| **Body Text** | 15px | 18px | 1.8-2.0 | `text-[15px] lg:text-[18px] leading-[1.8] lg:leading-[2]` |
| **Small Body** | 14px | 15px | 1.6-1.8 | `text-[14px] lg:text-[15px] leading-[1.6] lg:leading-[1.8]` |
| **Metadata** | 11px | 12px | 1.5 | `text-[11px] lg:text-[12px]` |
| **Labels (Uppercase)** | 13px | 13px | 1.5 | `text-[13px] tracking-[0.15em] uppercase` |
| **Small Labels** | 11px | 11px | 1.5 | `text-[11px] tracking-[0.12em] uppercase` |
| **Micro Text** | 10px | 11px | 1.5 | `text-[10px] lg:text-[11px]` |

### Font Weights

```css
/* Primary Text */
font-weight: 400; /* Regular - Use for all body text */
style={{ fontWeight: 400 }}

/* Medium (Rare Use) */
font-weight: 500; /* Medium - Only for strong emphasis */
style={{ fontWeight: 500 }}

/* Light (Special Cases) */
font-weight: 300; /* Light - Empty states, whisper text */
style={{ fontWeight: 300 }}
```

### Letter Spacing (Tracking)

| Use Case | Value | Tailwind Class |
|----------|-------|----------------|
| **Uppercase Labels** | 0.15em - 0.2em | `tracking-[0.15em]` or `tracking-[0.2em]` |
| **Small Uppercase** | 0.12em | `tracking-[0.12em]` |
| **Body Text** | wide | `tracking-wide` |
| **Metadata** | wide / wider | `tracking-wide` or `tracking-wider` |
| **Tags** | wider | `tracking-wider` |

### Typography Rules

1. **Always use inline styles for font-weight**: `style={{ fontWeight: 400 }}`
2. **Generous line-height**: Body text should breathe (1.8-2.2)
3. **Wide letter-spacing**: Creates spacious, zen-like feel
4. **Uppercase for labels only**: Section headers, navigation labels
5. **Never use bold for emphasis**: Rely on color and size changes

## 13. Design Principles Summary

### ✨ Core Philosophy
1. **Generous Negative Space** - Let content breathe
2. **Subtle Interactions** - No aggressive animations
3. **Earthy Color Harmony** - Warm, calming palette
4. **Japanese Minimalism** - Less is more
5. **Anti-SNS Design** - Focus over metrics

### 🎨 Visual Rules
- **Use exactly these hex codes** - Never deviate from palette
- **Font weight 400 by default** - Avoid bold text
- **Wide letter-spacing** - Creates spacious feel
- **Thin icon strokes** - Always `strokeWidth={1.5}`
- **Subtle borders** - Use opacity (20-50%) on base colors
- **Minimal shadows** - Only on hover, very soft
- **Rounded corners** - `rounded-sm` (4px) or `rounded-full`

### 📱 Interaction Rules
- **Mobile-first** - Base styles for mobile, `lg:` for desktop
- **Hover states** - Color shifts, subtle scale, soft shadows
- **Transitions** - Always smooth, default duration (150ms)
- **No aggressive states** - Everything gentle and calm
- **Focus visible** - Never remove accessibility

### 🌸 Zen Aesthetic
- One element at a time (Stream mode)
- Horizontal typography priority
- Clean, non-intrusive UI
- Contemplative pacing
- Emotional authenticity over metrics

- [ ] All colors from official palette (#FAFAF8, #3D3D3A, #D4CFC3, #A8A89E, #9B9890, #E8E6E0, #F5F4F0, #C5A088)
- [ ] Font weight 400 for body, 300 for whisper text
- [ ] Letter spacing on all text (`tracking-wide`, `tracking-[0.15em]`)
- [ ] Icon strokeWidth={1.5} or strokeWidth={2}
- [ ] Mobile-first responsive classes (base, then `lg:`)
- [ ] Smooth transitions on interactive elements
- [ ] Proper ARIA labels on buttons
- [ ] Japanese IME support (Enter key, not Space)
- [ ] Generous padding and negative space
- [ ] Subtle hover states (no jarring animations)
